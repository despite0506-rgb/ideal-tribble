# 온길 · 학원 시간표

학생별 주간 수업과 등·하원 차량 이용을 한 화면에서 관리하는 React/TypeScript 웹앱입니다.

배포 주소: <https://despite0506-rgb.github.io/ideal-tribble/>

![온길 시간표 데스크톱 화면](screenshots/desktop.png)

## 주요 기능

- 학생별 주간 시간표 필터
- 서로 다른 학생의 동시간대 수업을 나란히 표시
- 1분 단위 시작·종료 시간
- 두 명 이상 인원 제한 없이 구성하는 그룹 수업
- 학생별 상세 페이지, 피드백 기록 및 Notion 페이지 연결
- 학원 이름과 시간표 표시 범위 설정
- 수업 참가자별 등원·하원 차량 설정
- 학생과 수업 등록·수정·삭제
- 모바일 일간 목록과 데스크톱 주간 타임라인
- 브라우저 `localStorage` 자동 저장

처음 실행하면 기능을 바로 확인할 수 있도록 예시 학생과 수업이 표시됩니다. 데이터는 현재 브라우저에만 저장되며, 여러 기기 간 동기화나 계정 기능은 포함하지 않습니다.

## 실행

```bash
pnpm install --frozen-lockfile
pnpm dev
```

기본 개발 서버 포트는 `3000`입니다.

## 검증

```bash
pnpm typecheck
pnpm test
pnpm build
```

시간 변환, 동일 학생 충돌 방지, 동시간대 다수 학생 허용, 그룹 수업 무결성, 차량 상태, 겹침 레이아웃 및 저장 데이터 검증을 테스트합니다.
